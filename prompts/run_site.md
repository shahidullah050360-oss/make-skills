# RUN SITE 1..4

Runs the full `run_all.md` workflow scoped to a single site from
`config/websites.json`, filtering every data file (`data/02..08_*.csv`) to
that Site ID only. Never mixes prospects, keywords, content, or backlink
opportunities across sites unless an opportunity is genuinely relevant to
more than one site (note this explicitly in the `Notes` column when it
happens).
