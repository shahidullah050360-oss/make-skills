# RUN CONTENT

Finds content opportunities (Master Prompt Section 13). Every entry in
`data/07_Content.csv` must provide genuine reader value independent of any
backlink — never generate volume for its own sake.

For each opportunity, capture: Title, Primary keyword, Search intent,
Target audience, Content type, Suggested outline, Unique value, Required
sources, Internal linking opportunities, External references, Status.

Cross-reference `data/02_Keywords.csv` for the keyword and intent, and
`config/websites.json` for the target site's niche/audience so content
opportunities are never mixed across sites without genuine cross-site
relevance (Section 37).
