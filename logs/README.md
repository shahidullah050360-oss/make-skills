# logs/

Execution logs for each RUN command go here as
`logs/<command>-<YYYY-MM-DD-HHMM>.log`, capturing which tools were called,
which API calls failed (mirrored into `data/10_Errors.csv`), and how many
rows were added/updated in each `data/*.csv` file. No runs have executed
yet — this repo currently holds only the initial scaffolding commit.
